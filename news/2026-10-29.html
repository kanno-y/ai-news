Cursor：Design Mode の Annotate で画面を指さして直させる

Agents Window のブラウザで Cmd + Shift + D（または Annotate）を押すと、要素をクリックしたり範囲を囲んだりしてメモを書けます。Batch edits をオンにすると、メモをまとめて1回で送れます（Cursor 3.24.18 以降）。

共有用

Cursor の Design Mode に Annotate が入り、動いている画面の要素をクリックしたり範囲を囲んだりしてエージェントに直してほしい箇所を伝えられるようになりました。ブラウザで Cmd+Shift+D で開けて、Batch edits をオンにすると複数のメモを一度に送れます。 https://cursor.com/docs/agent/design-mode

👥 チームTips

Vercel AI Gateway：モデル設定を「仮想モデル」にまとめる

モデル、推論の強さ、フォールバック、Zero Data Retention などをまとめた設定に vmc/coding-agent のような ID を付けて呼べます。vercel ai-gateway virtual-models create で作れ、アプリを再デプロイせずにモデルを差し替えられます。

共有用

Vercel AI Gateway に「仮想モデル」が入り、モデルやフォールバック、データ保持なしの設定をまとめて vmc/〇〇 という ID で呼べるようになりました。中身は Gateway 側で変えられるので、アプリやエージェントを再デプロイせずにモデルを切り替えられます。 https://vercel.com/changelog/virtual-models-now-available-on-ai-gateway
