👥 チームTips

Claude Code が編集したファイルを hook で毎回 Prettier 整形する

settings.json の hooks に PostToolUse（matcher Edit|Write）で jq -r '.tool_input.file_path' | xargs npx prettier --write を登録すると、プロンプトで頼まなくても編集のたびに必ず整形されます。登録できたかはプロンプトで /hooks を開けば確認できます。

共有用

Claude Code の hooks で、ファイル編集のたびに Prettier を必ず走らせられます。settings.json の hooks に PostToolUse（matcher: Edit|Write）を足すだけで、指示し忘れても整形されます。 https://code.claude.com/docs/en/hooks-guide

👥 チームTips

入力待ちになったらデスクトップ通知を出す

~/.claude/settings.json の Notification hook に、macOS なら osascript、Linux なら notify-send を登録すると、許可待ちや入力待ちのときに通知が来てターミナルを見張らずに済みます。macOS で何も出ないときは「システム設定 > 通知」でスクリプトエディタの通知を許可します。

共有用

Claude Code が入力待ちになったらデスクトップ通知を出せます。~/.claude/settings.json に Notification hook を足すだけです。Mac で通知が出ないときは、システム設定の通知でスクリプトエディタを許可すると出るようになります。 https://code.claude.com/docs/en/hooks-guide
