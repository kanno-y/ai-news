🔒 セキュリティ要確認

Cursor マーケットの偽 Claude Code 拡張：自分のマシンに svc-telemetry がないか確認する

10月29日（PT）、Cursor の VS Code Extension Marketplace に Anthropic 製ではない Anthropic.claude-code 2.1.312 / 2.1.313（Windows・macOS）が出回り、ホスト情報の送信と SSH キー追加・永続化を試みていました。拡張を消しても永続スクリプトは残ることがあるので、まず鍵コメントを見ます。

👉 やってみる：macOS / Linux なら次を実行する（Windows は公式の PowerShell 版を使う）。
grep -qs svc-telemetry ~/.ssh/authorized_keys && echo "svc-telemetry key found" || echo "No key found; machine not impacted"
見つかったら公式の remediation スクリプトを実行し、そのマシンから触れる認証情報を信頼できる端末からローテーションする。Cursor 拡張の一覧で Claude Code の版も確認する。

🧭 エージェント活用スキル

AGENTS.md は「何をするか」を検証できる文だけに絞る

人気リポジトリ100件の調査では、中央値は92行で、見出しに多いのはコミット／PR ルールとセットアップ・実行コマンドでした。「きれいに書く」ではなく「pnpm vitest run path/to/file.test.ts を走らせる」のように、エージェントも人も合否を判定できる文にします。

👉 やってみる：個人リポジトリのルートに次の骨格を置き、コマンドだけ自分のスタックに直す。
# Commands - Install: pnpm install - Test one file: pnpm vitest run path/to/file.test.ts - Typecheck: pnpm tsc --noEmit # Never - Never hand-edit generated/ - Never commit secrets; read from env
Claude Code も使うなら隣に @AGENTS.md だけの CLAUDE.md を置くか、両方読みたいときは /config の Project instructions を claude-md-and-agents-md にする。

🔒 セキュリティ

🔒 セキュリティ

MCP のツール応答は信頼しない：権限のあるツールを別コンテキストに分ける

OWASP の MCP Tool Poisoning は、接続時に見たツール説明は普通でも、実行時の応答に隠し指示を混ぜてエージェントを動かす攻撃です。プロンプトで「外に出るな」と書いてあっても、実行レイヤで止めないと上書きされます。

👉 やってみる：今日のうちに次の3点を自分の設定に当てはめる。(1) 外部 MCP と、ファイル／シークレット／社内 API を触るツールを同じセッションに載せない。(2) 破壊的・送信系の呼び出しは人がパラメータ全文を見て承認する。(3) 可能ならツール出力を固定 JSON スキーマにし、形が違う応答は捨てる。設定の棚卸しは次で。
rg -n '"mcpServers"|mcp' ~/.claude.json ~/.cursor/mcp.json .mcp.json .cursor/mcp.json 2>/dev/null | head -40

Orca v1.4.250：チャットで変更ファイルを見て、長いターンでも切れにくくする

11月5日のリリースで、Claude／Codex の編集結果がチャットに変更ファイルと行数で出るようになり、パッチもその場で開けます。ターミナルのフォント解析をやめてメモリを抑え、128件を超えるツール多用ターンでもチャットが切れにくくなりました。ブラウザには Chrome 互換のパスワードマネージャも入ります。

👉 やってみる：Orca を 1.4.250 以上に更新し、いつも使うエージェントで小さな編集を1回頼む。チャットに変更ファイルの要約が出るか確認し、必要なら行をクリックしてパッチを見る。パスワード保存は Settings → Browser で有効化し、OS のセキュアストレージが使えるマシンだけで使う。

v2.1.318 で、mod の $.model.fork に effort を付けられるようになりました。本線が高めの努力でも、調べものや要約などの短い脇作業だけ低努力で回せます。結果には実際に送った effort が報告されます。

Orca：アイドル中のチャットエージェントを止めるか残すかを設定できる

v1.4.249 以降、アイドルになったチャットエージェントをいつ止めるか（または Never で残すか）を選べます。止めることと会話の削除は別です。

共有用

Orca（v1.4.249〜）では、アイドルになったチャットエージェントをいつ止めるか、または Never で残すかを設定できます。長い調査を途中で切られたくないときは Never、マシン負荷を抑えたいときは短めの停止にすると便利です。https://github.com/stablyai/orca/releases/tag/v1.4.249

CLAUDE.md と AGENTS.md を両方読ませたいときは Project instructions を変える

👥 チームTips

MCP ツールはスキーマをピン留めし、説明文が変わったら再承認する

OWASP の MCP Security Cheat Sheet は、ツール定義（説明・inputSchema・annotations）をハッシュなどで固定し、変更時は再レビューするよう勧めています。接続時だけ見て実行時を見ないのがギャップです。

共有用

MCP サーバーは、接続時に見たツール説明が後から書き換わる「ラグプル」があり得ます。OWASP の推奨どおり、ツール定義をレビューしてピン留めし、説明やスキーマが変わったら再承認する運用にすると安心です。https://cheatsheetseries.owasp.org/cheatsheets/MCP_Security_Cheat_Sheet.html
