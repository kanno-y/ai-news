Cursor CLI の agent -p は、--force なしなら提案だけ

ヘッドレスの print モードは、--force（または --yolo）を付けない限りファイルを変更せず提案だけを返します。--output-format json を付ければ、CI でレビュー結果を機械的に扱えます。

共有用

Cursor CLI の agent -p は --force を付けない限りファイルを書き換えず、提案だけ返します。CI でのレビューやコード調査には --force なし、--output-format json で結果を受け取るのが安全です。 https://cursor.com/docs/cli/headless

👥 チームTips

xAI API のレスポンスで、そのリクエストの料金を直接見る

xAI API はすべてのレスポンスの usage に cost_in_usd_ticks を返し、チャット・Responses API・画像や動画生成・ストリーミングのどれでもリクエストごとの正確な料金がわかります（1ドル＝1010 ticks）。

共有用

xAI（Grok）API はレスポンスの usage.cost_in_usd_ticks にそのリクエストの料金を入れて返します。ログに残しておけば、トークン数から料金を計算し直さなくても機能ごとのコストを集計できます（ticks を 1e10 で割るとドル）。 https://docs.x.ai/developers/cost-tracking

👥 チームTips

IAM ポリシーのチェックに AWS の「サービスリファレンス情報」を使う

AWS は全サービスのアクションや条件キーを機械可読な形で公開していて、aws: で始まるグローバル条件キーの一覧や、アクションがデータプレーンかを示す IsDataPlane も入りました。ポリシーの自動レビューやエージェントの権限チェックに使えます。

共有用

AWS のサービスリファレンス情報（機械可読な JSON）に、グローバル条件キー一覧とデータプレーン操作かどうかの区別が入りました。IAM ポリシーの自動チェックの元データに使えます。 https://aws.amazon.com/about-aws/whats-new/2026/10/aws-service-reference-information-global-condition-keys-service-names-data-plane/
