Claude Code v2.1.323：deny/サンドボックスのすり抜けを多数修正、サンドボックス内の git worktree add は失敗するように

11月13日 7時ごろ（日本時間）のリリースで、sudo・env 経由のコマンドに deny/ask ルールが効かない、Read の deny 対象に Write/Edit で書ける、claude -p でサンドボックス設定が不正だとサンドボックスなしで Bash が動く、といった問題が直りました。一方で、macOS/Linux のサンドボックスでは git worktree add/move/remove が読み取り専用で失敗するようになり、.mcp.json の MCP サーバー承認は名前の完全一致になりました（表記が違えば再確認）。

👉 やってみる：まず上げて、許可ルールに「変数に *」の形がないか探す（この版から起動時に警告され、Bash(NODE_ENV*) のような形は確認が出るようになりました）。
claude update && claude --version && rg -n 'Bash\([A-Z_]+=?\*|Bash\([a-z]+\*\)' ~/.claude/settings.json .claude/settings*.json
Claude にサンドボックス内で worktree を作らせていた手順があれば、worktree は Orca 側で作るてから、その中で Claude Code を起動する形に切り替える。

並列エージェントは「1人のコーディネーター＋明示した優先順位」で回し、他の作業を読むまでコミットさせない

Anthropic の研究（11月11日）では、人ごとにエージェントを立てて直接やり取りさせるより、1つのコーディネーターが全員分を受け持つほうが、4つの環境すべてで成果が良くなりました。共有予算では「リーダーを決めて優先順位を明記」、グループ注文では「メッセージを読むまで発注させない」が効いたと報告されています。

👉 やってみる：Orca で worktree を分けて複数のチャットを走らせるときは、1つを調整役にして最初にこう送る。
あなたはこの作業のコーディネーターです。自分ではコードを書かず、各ワーカーの担当・優先順位・マージ順を決めて coordination.md に書いてください。優先順位は (1) 既存テストを壊さない (2) GraphQL スキーマの変更は1か所にまとめる (3) その他、です。各ワーカーには「コミット前に必ず coordination.md と他ワーカーの最新メモを読み、自分の変更が他の担当と衝突しないか一文で書いてからコミットする」と指示してください。衝突したら作業を止めてあなたに報告させてください。
ワーカー側のチャットには「coordination.md の自分の担当だけをやる」と1行添える。

進行中の wfx-loot：GitHub Actions と npm postinstall で AWS 鍵や AI の API キーを盗み、痕跡を消す

OX Security によると、乗っ取られた 4,837 の GitHub アカウントが「docs: dependency audit notes」という探りの PR を出し、書き込めるリポジトリに CI 保守を装ったコミットを入れて数分で戻し、ワークフロー実行とログも消しています。少なくとも 1,806 リポジトリで秘密が送られ、11月12日時点でも続いています。

👉 やってみる：自分が書き込めるリポジトリで、探りの PR と偽装コミットを探す（OWNER は自分の組織名やユーザー名に置き換え）。
gh search prs "docs: dependency audit notes" --owner OWNER gh search commits "ci: refresh build cache" --owner OWNER gh search commits "chore: add ci helper" --owner OWNER
見つかったら、そのワークフローから届く Secrets と AWS ロールを全部ローテーション対象にする。AWS では「誰でも引き受けられる」信頼ポリシーのロールが足されていないかも見る。
aws iam list-roles --output json | rg -n -B8 '"AWS": "\*"'

「エージェントを遠隔操作する npm」を見つける：ANTHROPIC_BASE_URL と --dangerously-skip-permissions を点検

11月9日に GitHub が @bestcoolman/dev-mcp をマルウェアと公表し、Kuntur は OSV に記録のある同じ系統の npm を19件まとめています。Claude Code の通信先を書き換えて API キーと全プロンプトを送るもの、遠隔の指示で claude --dangerously-skip-permissions を起動するものなどで、11月10日時点で17件がまだ npm にありました。

👉 やってみる：Claude Code の設定に、自分が入れていない通信先や鍵の取得コマンドがないかと、確認なしモードで動く claude がいないかを見る。
rg -n "ANTHROPIC_BASE_URL|apiKeyHelper" ~/.claude/settings.json ~/.claude.json .claude/ 2>/dev/null; ps aux | rg -- "--dangerously-skip-permissions" | rg -v rg; npm ls -g --depth=0 | rg -i "claude|agent|mcp|anthropic"
知らないホストが出たら、そのマシンをネットから外し、別の端末から Anthropic・GitHub・AWS の鍵を差し替える。

Cursor Projects がマルチプレイに：チームの人のエージェントと、タスクボードと仕様を共有して作業する

Projects（コーディネーターが Cloud Agent に作業を配るしくみ）に、チームメンバーを招待できるようになりました（ベータ）。各自が自分のコーディネーターを持ち、タスクボードと「Context」（要件・仕様・図）を共有し、コーディネーター同士が直接やり取りして衝突を先に避けます。相手のエージェントからのメッセージは信頼しない入力として扱われ、横のチャットは秘密を渡しません。

👉 やってみる：使えるのはチームアカウントで Cursor 3.26.13 以上、相手がリポジトリにアクセスできる場合です。Cursor の About 画面で版を確認し、左のナビから Project を作って Invite teammates to this project で招待する。最初にコーディネーターへこう送る。
このプロジェクトの Context に、要件・受入条件・触ってよいディレクトリと触らないディレクトリ・検証コマンド（npm test など）をまとめたページを作ってください。以後、どのメンバーのエージェントも作業前にこのページを読み、タスクボードの担当外のファイルは変更しないでください。
共有の Context に社外秘を置いてよいかは、チームのルールで先に決めておく。

👥 チームTips

/compact は上限で自動に任せず、タスクの切れ目で「残すもの」を指定して実行する

OptiFlume の測定では、文脈の増加の58%はモデル自身の返信と思考でした。自動要約は一度だけ出た制約やエラー文を落としやすいので、区切りで残す項目を指定して圧縮すると、後半の取り違えが減ります。

共有用

Claude Code の /compact は、上限で自動に任せるより、タスクの区切りで「/compact 目標・決定事項・制約・失敗した方法・次の一手を残して」のように残すものを指定して実行すると、後半で制約を忘れにくくなります。https://optiflume.ai/learn/context-engineering-for-coding-agents

Claude Code：サブエージェントの途中経過サマリーを切って、その分のリクエストを減らす

v2.1.323 で、CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES=1 が文書化されました（2.1.318 から有効）。サブエージェントの進捗要約と、それを書くためのリクエストが止まるので、並列でたくさん走らせるときの消費を抑えられます。

👥 チームTips

.claude/settings.local.json が git に入っていないか確かめる

v2.1.323 から、秘密を含みそうな許可ルールや、git 管理下の settings.local.json に保存されそうなルールは「次回から聞かない」を選んでもそのセッション限りになりました。そもそも個人用の設定ファイルが追跡されていないかを見ておくと、許可ルールやトークンの混入を防げます。

共有用

Claude Code の個人用設定 .claude/settings.local.json が git に入っていないか、git ls-files .claude/settings.local.json で一度確かめておくと安心です。出てきたら .gitignore に足して git rm --cached で外しましょう。https://github.com/anthropics/claude-code/releases/tag/v2.1.323
