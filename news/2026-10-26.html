Claude Code：2分を超える MCP 呼び出しは自動でバックグラウンドへ

メインの会話で MCP ツールの呼び出しが2分を超えるとバックグラウンドタスクに移り、Claude は待たずに作業を続けて、結果は通知で届きます。/tasks で確認・停止でき、しきい値は CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS（ミリ秒、0 で無効）で変えられます。

共有用

Claude Code では MCP ツールの呼び出しが2分を超えると自動でバックグラウンドに回り、/tasks で進み具合の確認や停止ができます。結果を待たせたいときは環境変数 CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS を 0 にすると無効化できます。 https://code.claude.com/docs/en/mcp#automatic-backgrounding-of-long-tool-calls
