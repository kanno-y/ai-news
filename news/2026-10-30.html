Vercel で Node.js 26 LTS が GA、設定によっては次のデプロイから自動で移行

ビルドと Vercel Functions で Node.js 26 が使えるようになり、新規プロジェクトのデフォルトになりました。組み込みの fetch はデフォルトで HTTP/2 を使います。

💡 package.json の engines.node を確認し、まだ上げたくなければ 24.x などに固定します。HTTP/1.1 のままにしたいときは環境変数 VERCEL_FETCH_DISABLE_H2=1 を設定して再デプロイします。

Orca v1.4.244：リモート SSH のファイル保存とターミナルの安定化

リモート SSH 上のファイルをローカルと同じように保存できるようになり（最大50MB）、Windows で新しいターミナルがすぐ使えない問題や macOS/Linux での固まりも直りました。

💡 アップデート後、ターミナル修正の一部はターミナルホストの再起動で反映されます。リモート先の Orca サーバーも同じバージョンにそろえ、worktree の場所を ~ 始まりで書いている場合はホームフォルダとして解釈されるようになった点を確認します。

Grok API：guidelines でカテゴリごとに応答を控えさせる

Chat Completions と Responses API のリクエストに guidelines を入れると、nsfw・violence・profanity を decline（応じない）に指定でき、すべての API 利用者が使えます。

💡 {"type":"policy","category":"profanity","behavior":"decline"} を足して試します。指定はそのリクエストだけに効くので毎回送ります（OpenAI Python SDK では extra_body に入れます）。マルチエージェントモデルでは使えません。

Claude Code：/rewind の「Summarize from here」で長いデバッグを圧縮

/rewind（または Esc を2回）で地点を選んで「Summarize from here」を選ぶと、そこから後ろの会話だけが要約されて文脈が軽くなります。ファイルはそのままで、要約の観点も指示できます。

共有用

Claude Code で長いデバッグのあと文脈が重くなったら、/rewind から「Summarize from here」を選ぶと、最初の指示を残したまま後半だけ要約できます。ファイルは変わりません。https://code.claude.com/docs/en/checkpointing
